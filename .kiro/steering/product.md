# Product Overview

## Flip Clock App

A customizable flip clock application built with React that provides both clock and timer functionality with visual flip animations.

### Key Features

- **Clock Mode**: Real-time digital clock with flip card animations
- **Timer Mode**: Countdown timer with customizable duration
- **Customization**: Theme system supporting background colors/images, fonts, and color schemes
- **Responsive Design**: Clean, modern interface with full-screen background support
- **Persistent Settings**: User preferences saved to localStorage

### User Experience

- Simple mode switching between clock and timer
- Intuitive customization panel for theming
- Timer controls with play/pause/reset functionality
- Settings panel for timer duration configuration
- Smooth flip animations for time transitions
